# IMC Prosperity 4 Trading Challenge

Algorithmic trading system to compete in IMC's simulated exchange.

## Strategies Implemented
- **Mean reversion**: Trade around predetermined fair value
- **Market Making**: Spread capture with inventory control
- **Basket Arbitrage**: Exploiting mispricing between correlated products
- **Signal-Based Trading**: Reaction to informed trader activity

## Results
- Achieved consistent profitability across multiple simulated rounds
- Optimised trade-offs between risk and execution fees

## Repository Structure
- `analysis/`: research and strategy identification
- `archive/`: round-by-round development history
